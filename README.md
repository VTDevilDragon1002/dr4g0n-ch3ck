# dr4g0n-ch3ck

A professional static password checker website for cybersecurity students.

## Pages
- `index.html` - Landing page
- `check.html` - Password checker dashboard
- `assets/css/style.css` - Full design and animation
- `assets/js/checker.js` - Password analysis logic

## GitHub Pages Deploy
1. Upload this folder to a GitHub repository.
2. Go to Settings > Pages.
3. Select branch: `main`, folder: `/root`.
4. Open the generated GitHub Pages URL.

## Features
- Password strength score
- Entropy estimate
- Crack-time estimate
- Common word and pattern checks
- Strong password generator
- Modern cyber UI animations
